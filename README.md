# Цифровий двійник автоматичної кавомашини

ЛР1 описує архітектуру платформи, вимоги й модель SysML v2. ЛР2 реалізує локальний стенд для двійника `org.pzks:cm-001`, перевіряє узгодженість стану та вимірює затримку під навантаженням.

## ЛР2. Локальний стенд і перевірки

1. [Розгорніть стенд](docs/platform.md#розгортання-платформи) з Eclipse Ditto, Mosquitto, InfluxDB і Grafana.
2. [Створіть політику та двійник](docs/information-model.md#перевірка-валідності) за моделлю W3C WoT. У цьому ж розділі наведено результати перевірки обмежень моделі.
3. З кореня репозиторію підготуйте Python-середовище.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

4. [Підключіть MQTT та запустіть емулятор](docs/telemetry.md#запуск-та-перевірка-каналу). Вебподання працює за адресою [localhost:8090/ui/](http://localhost:8090/ui/).
5. [Запустіть історик і повторіть вимірювання](docs/sync.md). Результати контрольних і навантажувального прогонів є в [results/](results/), а їхній зв'язок із вимогами наведено в [матриці трасовності](docs/traceability.md#фактичні-результати-лр2).

Маршрут телеметрії на стенді — емулятор → MQTT/Mosquitto → Ditto. Вебінтерфейс читає поточний стан через REST і SSE. Історик записує зміни з SSE в InfluxDB, а Grafana відображає часові ряди.

## ЛР1. Архітектура та SysML v2

- [Вимоги та реєстр восьми сигналів](docs/requirements.md). Розрахунковий обсяг необроблених значень становить близько 22,3 МБ/добу.
- [Архітектурні подання](docs/diagrams/), [зіставлення з ISO 23247](docs/iso23247-mapping.md), [архітектурні рішення](docs/adr/) і [джерела](docs/sources.md).
- [Модель затримки](docs/latency.md) та [розрахунок у Python](docs/latency.py). Для гіпотези Г-01 проєктні оцінки становлять 340 мс для REST polling і 210 мс для WebSocket push, тобто очікуване скорочення на 38,2 %.
- [Модель SysML v2](model/model.ipynb) містить вимоги, структуру, порти, сценарій оброблення телеметрії, зв'язки `satisfy` та визначення перевірок. Для редагування потрібен JupyterLab з ядром SysML v2 Pilot Implementation. [HTML-експорт](model/export/model.html) відкривається у браузері.
